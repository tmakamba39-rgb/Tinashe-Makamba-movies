# Tinashe Makamba Movie App — GitHub Ready

This package is prepared for building an Android APK with GitHub Actions.

## Uploading from an Android phone

1. Extract this ZIP on your phone.
2. Open the extracted **FreeCinema** folder.
3. Select everything inside it, including the **.github** folder.
4. In your GitHub repository, choose **Add file → Upload files**.
5. Upload the selected project files/folders and commit them to `main`.
6. Open the **Actions** tab.
7. Open **Build Tinashe Makamba APK**.
8. Wait for the workflow to finish.
9. Open the completed workflow run and download the **Tinashe-Makamba-debug-apk** artifact.
10. Extract the artifact and install `app-debug.apk` on your Android phone.

Do not upload `local.properties` or the ZIP itself.

The download feature in the app only works with direct media URLs that the source explicitly permits. The app does not bypass subscriptions, DRM, or copyright restrictions.
